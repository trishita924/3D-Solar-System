# 3D Solar System Explorer

An interactive 3D Solar System built using **HTML, CSS, JavaScript, and Three.js**.

Explore the Sun and all eight planets in a 3D environment. Rotate the view, zoom in and out, control planetary motion, and discover interesting facts about each planet.

## Live Demo

https://trishita924.github.io/3D-Solar-System/

## Features

- Interactive 3D Solar System
- All eight planets with orbital paths
- Click on planets to explore their information
- Rotate and zoom the 3D view
- Pause and resume planetary motion
- Adjustable animation speed
- Responsive interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Three.js

## Project Objective

To create an interactive and educational 3D experience that helps users explore the Solar System and understand basic planetary information.
